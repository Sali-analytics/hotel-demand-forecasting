# Hotel Demand Forecasting

This project builds a time series forecasting model for hotel demand using Python. 
It includes occupancy, ADR, RevPAR, booking window, and pickup analysis.

## 📊 Features
- Time series forecasting (ARIMA, Prophet)
- Daily occupancy and ADR trends
- Pickup and pace integration
- Visualizations for demand behavior

## 🧰 Tools Used
- Python (Pandas, NumPy, Matplotlib)
- Jupyter Notebook
- Synthetic hotel dataset
